# Phone Monitor - مراقب أداء الهاتف

تطبيق أندرويد بسيط لعرض معلومات الأداء (البطارية، الحرارة، الرام، تردد المعالج، الوقت)
في نافذة عائمة قابلة للتخصيص (شفافية، حجم خط، لون، موقع) تظهر فوق أي تطبيق أو لعبة.

## ⚠️ ملاحظة مهمة عن الحدود التقنية
- **FPS واستخدام GPU لتطبيقات أخرى (كالألعاب) غير مدعومَين**: أندرويد لا يسمح لتطبيق
  عادي بدون Root بقياس أداء عملية تطبيق آخر. هذا قيد نظام تشغيل وليس نقصاً في الكود.
- **نسبة استخدام CPU الدقيقة** غير متاحة أيضاً؛ التطبيق يعرض بدلاً منها **تردد المعالج
  الحالي بالميجاهرتز** كتقدير تقريبي لمدى انشغال المعالج.

## خطوات إصدار ملف APK عبر GitHub (بدون أي برمجة)

1. أنشئ حساباً مجانياً على https://github.com إن لم يكن لديك واحد.
2. اضغط على "New repository"، اختر اسماً (مثلاً `PhoneMonitor`)، واجعله **Public**، ثم أنشئه.
3. داخل صفحة المستودع الفارغ، اضغط "uploading an existing file".
4. اسحب وأفلت **جميع محتويات هذا المجلد المضغوط بعد فك ضغطه** (بما فيها مجلد `.github`) في تلك الصفحة، ثم اضغط "Commit changes".
   - **مهم:** تأكد أن مجلد `.github/workflows/build.yml` وصل فعلاً ضمن الرفع (بعض المتصفحات تخفي المجلدات التي تبدأ بنقطة؛ إذا لم يظهر، ارفعه بشكل منفصل من خلال "Add file → Create new file" واكتب المسار كاملاً `.github/workflows/build.yml` والصق محتواه).
5. بعد الرفع، اذهب إلى تبويب **Actions** أعلى صفحة المستودع.
6. ستجد عملية بناء (workflow) تعمل تلقائياً باسم "Build APK". انتظر حتى تكتمل (دائرة خضراء ✓)، تستغرق عادة 2-5 دقائق.
7. اضغط على العملية المكتملة، ثم انزل لقسم **Artifacts** أسفل الصفحة، واضغط على `PhoneMonitor-debug-apk` لتحميله كملف مضغوط يحتوي على `app-debug.apk`.
8. انقل الملف لهاتفك، وقبل التثبيت فعّل خيار "السماح بالتثبيت من مصادر غير معروفة" لمتصفحك أو تطبيق الملفات (يظهر أندرويد هذا الخيار تلقائياً عند محاولة فتح الـ APK لأول مرة).
9. ثبّت التطبيق، امنحه صلاحية "العرض فوق التطبيقات الأخرى" من داخله، ثم شغّل النافذة العائمة.

## طريقة الاستخدام داخل التطبيق
1. افتح التطبيق واضغط "منح صلاحية النافذة العائمة" واسمح بها من إعدادات أندرويد.
2. عد للتطبيق واضغط "تشغيل النافذة العائمة".
3. اضغط "⚙ إعدادات التخصيص" لاختيار العناصر الظاهرة، الشفافية، حجم ولون الخط.
4. أغلق التطبيق أو انتقل لأي لعبة/تطبيق آخر — ستبقى النافذة العائمة ظاهرة.
5. لتحريك موقع النافذة، اسحبها بإصبعك مباشرة على الشاشة.
6. لإيقافها، افتح التطبيق واضغط "إيقاف"، أو اضغط زر "إيقاف" في الإشعار الدائم.
